# Интеллектуальный ассистент по уходу за растениями

Проект по дисциплине **«Технологии интернета вещей»**.

## Описание

Цель проекта — разработать IoT-систему для наблюдения за растением и анализа его состояния с помощью искусственного интеллекта.

В качестве основного устройства планируется использовать **ESP32-CAM**, которая будет периодически фотографировать растение и передавать изображения на сервер.

Дополнительно система будет получать данные с датчиков окружающей среды:

- температура воздуха;
- влажность воздуха;
- влажность почвы.

На сервере искусственный интеллект будет анализировать фотографию растения и показания датчиков, определяя его текущее состояние.

Система должна уметь не только определять необходимость полива, но и оценивать **здоровье растения по его внешнему виду**: состояние листьев, изменение цвета, признаки увядания, высыхания и другие визуально заметные проблемы.

## Основные задачи

- получение изображений растения с ESP32-CAM;
- получение показаний с датчиков;
- передача данных на сервер по Wi-Fi;
- хранение истории наблюдений;
- анализ внешнего вида растения с помощью ИИ;
- определение признаков ухудшения состояния растения;
- определение необходимости полива;
- отображение информации о состоянии растения пользователю.

## Предполагаемая схема работы

```text
ESP32-CAM
    │
    ├── Фотография растения
    ├── Температура
    ├── Влажность воздуха
    └── Влажность почвы
            │
            ▼
          Сервер
            │
            ▼
       AI-анализ
            │
     ┌──────┴──────┐
     ▼             ▼
Анализ здоровья   Решение
   растения       о поливе

```

## Используемые компоненты

- **ESP32-CAM** — получение изображений и передача данных;
- **KY-015 / DHT11** — измерение температуры и влажности воздуха;
- **датчик влажности почвы**;

## AI-анализ

ИИ будет получать фотографию растения и определять его состояние.

Предполагается анализ следующих признаков:

- увядание;
- пожелтение листьев;
- высыхание;
- повреждения листьев;
- изменение внешнего вида растения со временем;
- общее состояние растения.

Результаты визуального анализа будут дополняться данными с датчиков.

```text
Фотография + влажность почвы + температура + влажность воздуха
                              ↓
                         AI-анализ
                              ↓
              Состояние растения и рекомендации
```
